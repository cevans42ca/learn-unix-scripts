# Junie Guidelines for learn-unix-scripts

## Documentation for LLMs
- **IMPORTANT**: Always refer to [LLM_GUIDE.md](../LLM_GUIDE.md) for tone, structure, and technical requirements when creating or modifying educational content.

## Code Modification Rules
- **NEVER** modify files in `main/dist/bin/` directly. These are generated by `main/replace-all`.
- **ALWAYS** modify the corresponding master script in `main/master-scripts/` (e.g., `learn-master` for `learn`).
- Use the replacement system in `main/replacements/` for shared logic and `main/site-install/` for site-specific logic.
- Maintain the GUID-based markers (`# insert`, `# replace start/end`) to ensure the build process remains functional.

## Shell Compatibility
- Targets Bash 4.0+. Avoid features introduced in later versions if possible or provide fallbacks.
- Use `set -e -o nounset` where applicable (consistent with existing scripts).
- Use `fmt` for text wrapping, respecting the dynamic `$WIDTH` calculated in `learn-master`.

## Testing & Verification
- Test changes by running `main/replace-all` (or via `make`) and then executing the generated scripts.
- Use `verify` script to check environment compatibility.
- For Docker changes, verify with `main/docker/Makefile`.
